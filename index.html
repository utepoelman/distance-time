💡 Key Concepts Reference

  • Gradient (Slope) = Speed: Speed = Δdistance / Δtime = (d₂ - d₁) / (t₂ - t₁)
  • Flat Horizontal Line: Distance is unchanged → Object is stationary (stopped).
  • Steeper Line: Faster speed (covers more distance in less time).
  • Line Sloping Downwards: Moving backwards towards starting point or origin.
  • Intersection Point: Objects are at the exact same location at the same time.
